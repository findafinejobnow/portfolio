# 文学叙事意象四象限测试

> Vibe Coding 前端热身 Demo｜纯静态单页网站，无后端，浏览器本地运行。

## 项目简介

一个文学叙事风格测评工具。用户完成选择题，根据选择的叙事偏好，计算得到 2D 四象限坐标落点，展示对应的文学引文卡片。

坐标轴定义：

- X 轴：**解构 ←————→ 沉浸**（范围 [-100, 100]）
  - 负值：解构视角，抽离文本、分析叙事技法
  - 正值：沉浸视角，代入角色、感受故事体验
- Y 轴：**聚焦人物 ↑————↓ 聚焦氛围**（范围 [-100, 100]）
  - 正值：聚焦人物，关注角色内心、命运、人物关系
  - 负值：聚焦氛围，关注场景、物象、环境叙事

四象限：

1. 左上【解构-聚焦人物】 X 负，Y 正
2. 右上【沉浸-聚焦人物】 X 正，Y 正
3. 左下【解构-聚焦氛围】 X 负，Y 负
4. 右下【沉浸-聚焦氛围】 X 正，Y 负

## 技术栈

原生 HTML + JavaScript + Tailwind CSS

✅ 无框架、无后端、无需服务器，静态页面，可直接打开 index.html 运行
✅ LocalStorage 本地存储：保存答题进度与测评结果，数据仅保存在用户浏览器

## 三层数据架构【重要维护说明】

> 本项目数据严格分层解耦，**修改上层素材不会改动底层测评核心逻辑**

1. 🔒 底层内核层 `tags`【冻结，不建议后期修改】
   16 组叙事意象标签，绑定固定 (x, y) 坐标。
   > 一旦修改此数组，测评计算逻辑、最终落点结果会发生变化。项目开发完成后尽量保持不变。

2. 📖 素材库 `quoteLibrary`【可独立更新】
   16 条文学引文卡片，每条绑定对应标签，包含：引文原文、出处、核验链接。
   > 后续可以单独替换、新增、修改引文与出处信息，**完全不影响测评计算逻辑**。
   > 引文核验标准：
   > - 古典诗文：识典古籍 https://www.shidianguji.com/ 为主源核验
   > - 公版中文名著译本：国学大师 guoxuedashi.com 主源，必要时用书格 new.shuge.org 交叉核验
   > - 入库强制校验：页面 Ctrl+F 整句精确匹配原文；无痕浏览器复检链接；仅选用公版作品，规避版权风险。

3. 📝 测验包装层 `questions`【可自由迭代修改】
   测验题目：标题、情景故事、选项文本。
   > 可反复改写世界观、场景描述、选项措辞；**修改题目文本不会改动底层坐标与引文素材**。

## 运行方式

1. 本地：直接双击打开 `index.html`
2. 部署：上传至 GitHub Pages 静态网页服务

## 开发 & 维护流程

1. 固定底层 `tags` 标签坐标（冻结）
2. 搜集、核验文学引文，填充 `quoteLibrary`
3. 编写/迭代测验题目，填充 `questions`
4. 自测整套答题流程、坐标计算、LocalStorage 存储
5. 提交代码到 GitHub

## 仓库文件结构

### 测评维度设计说明

本测评选取两组互相独立的阅读偏好作为坐标轴：
- X 轴：**解构 ↔ 沉浸**（阅读姿态）
  - 解构：抽离故事，分析文本叙事手法、伏笔、隐喻；
  - 沉浸：代入故事，直接体验故事内的情绪与经历。
- Y 轴：**聚焦人物 ↔ 聚焦氛围**（阅读注意力落点）
  - 聚焦人物：注意力优先投向角色的情绪、动机、命运、人物关系；
  - 聚焦氛围：注意力优先投向环境、物象、空间、感官与意境氛围。

> ⚠️ 重要声明：本项目为文艺趣味 Demo，**不是专业心理人格量表**，结果仅作为阅读审美偏好的自我参考。
